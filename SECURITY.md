# Security policy

Report a suspected vulnerability privately through [GitHub's vulnerability reporting page](https://github.com/PhantomPixelDev/FluxPort/security/advisories/new). Do not put exploitable details, credentials or private datasets in a public issue. If private reporting is unavailable, open an issue requesting a private reporting channel without including the vulnerability details.

Include the affected version, operating system, configuration, a minimal synthetic reproduction and the expected impact. Security fixes target the latest release; older versions may require upgrading. This project does not promise a response-time SLA.

The hosted demo is a shared public workspace. Use a private installation for confidential data, configure authentication, restrict network exposure as appropriate and back up both source and metadata volumes.
