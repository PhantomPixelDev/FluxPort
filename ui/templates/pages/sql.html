Query limits and engine behavior
Only SELECT and WITH are allowed. Queries use a {{.SQL.DuckDBTimeoutSeconds}}-second DuckDB timeout, a 1,000-row preview and an 8 MiB result limit. Automatic mode selects DuckDB for joins, filters, sorts or aggregates over collections with 250,000+ records; simple queries stay native. First use builds a disk-backed cache. DuckDB spills within the configured memory and temporary storage limits. Use _json for original normalized values. Exports require a complete result.
