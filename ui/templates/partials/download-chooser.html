Format details

Matching rows across every page, in the displayed sort order.

Original file always downloads the complete source exactly, including every Excel sheet.

Excel saves values as text and nested values as JSON text. Null, missing and empty text become blank cells. Lossless Parquet stores complete records in one JSON column; typed Parquet creates analytical columns.

CSV stores nested values as JSON text. TOML uses a records wrapper and cannot represent null.
